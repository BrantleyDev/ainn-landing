Overview

AINN (Apple Intelligence News Network) is a single-operator technology-news project, currently in development. This policy explains what information this project handles and how.

This website

This landing page does not use cookies, does not run analytics or tracking scripts, and does not collect any personal information from visitors. It exists to describe the project and to satisfy the transparency requirements of third-party platforms that AINN connects to.

Connected platform accounts

AINN's software connects to the operator's own social media accounts (currently X, formerly Twitter) using that platform's official API and OAuth authorization flow. This connection is used solely to allow the operator to review and manually approve draft posts before they are published to the operator's own account. AINN does not access, read, or act on any account other than the operator's own, and does not collect or store data about other users of the platform beyond what is necessary to display a post the operator is reviewing (for example, confirming a post was published successfully).

Data storage

Authentication tokens and draft content are stored on infrastructure controlled by the operator and are not shared with, or sold to, any third party.

Changes to this policy

As AINN moves from development toward a public-facing service, this policy will be updated to reflect any change in what data is collected or how it is used.

Contact

Questions about this policy can be directed to the operator via the project's GitHub repository.
